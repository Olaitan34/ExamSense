# Project Documentation

This folder holds all planning, strategic, and final submission documents for the **ExamSense** project. It serves as the single source of truth for the project's non-technical documentation.

## Key Documents

* **Project Plan**: The initial brief and timeline for the 1-week build.
* **Meeting Notes**: Summaries and action items from team syncs.
* **Demo Script**: The script for our final 60-second video demo.
* **Final Submission**: The written document to be submitted at the end of the build week.
