# ExamSense

> A smart practice testing platform that helps WASSCE candidates identify their weak topics through AI-powered analysis and get personalized study recommendations—turning practice tests into targeted learning paths.

## About This Project

This is the first build-week project for the **Zenith 3** team, created as part of the **Programmify by PIP4 Internship**.

We are building a prototype of a Computer-Based Testing (CBT) platform designed specifically for students preparing for the WASSCE exams. Our core value is to move beyond simple scoring; we diagnose a student's performance by topic and provide a prescribed, targeted learning path to help them improve efficiently.
