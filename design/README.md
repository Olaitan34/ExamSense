# Design Assets

This folder contains all design-related assets for the **ExamSense** project. The goal is to create a clean, modern, and encouraging user interface for WASSCE candidates.

## Contents

* **Brand Identity**: Files or guidelines detailing our color palette, typography, and logo usage.
* **UI/UX Mockups**: Designs for the key application screens, including:
    * Landing Page
    * Test-Taking Interface
    * Results Dashboard
    * Personalized Report Page
* **Assets**: Exported icons, images, and other graphics used in the application.
